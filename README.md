## About

I'm a software engineer focused on backend systems and applied AI. I work end to end — API design, the data layer behind it, and the interface people use — primarily in **Java**, **Python** and **TypeScript**.

Recently I have been building reliable services with **Spring Boot**, **Node.js** and **FastAPI**, and applying language models responsibly: deterministic logic does the computing, the model does the explaining, and every output is validated before it reaches a user.

**Current focus**

- Backend architecture: REST design, authentication, persistence and deployment
- Applied AI systems with retrieval, guardrails and testable behaviour
- Data structures and algorithms in Java

## Selected work

### [ARC — AI-powered Review of Claims](https://github.com/Jashan37/ARC-AI-powered-Review-of-Claims)

An assistant that reviews health-insurance claims. It assembles the claim from uploaded documents, explains what is likely to be paid and why, and produces a PDF report for the insurer's team. All figures and policy rules are computed in plain Python; the language model only explains the result, and every response passes validation guards before it is shown.

`Python` · `Azure AI Search` · `Docker` · `Pytest`

### [Flix — Movie Rating Platform](https://github.com/Jashan37/Flix)

A Flask web application for browsing, searching, rating and reviewing films, with user accounts, hashed credentials and a personal rating history.

`Flask` · `SQLAlchemy` · `SQLite` · `Bootstrap`
