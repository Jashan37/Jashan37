## 👋 About me

I'm a developer who likes building things end to end: the API, the data behind it, and the screen people actually use. Most of my work is in **Java**, **JavaScript/TypeScript** and **Python**, and lately I've been pushing into backend architecture and applied AI.

- 🔭 Recently built **ARC**, an AI assistant that reviews health-insurance claims and explains the outcome in plain words
- 🌱 Currently deepening **Spring Boot**, **Node.js** and **FastAPI**: REST design, auth, databases and deployment
- 🧠 Sharpening problem solving daily with **data structures & algorithms** in Java
- 📊 Enjoy digging into data with **pandas**, **NumPy** and **Matplotlib**
- ⚡ Fun fact: I learn best by rebuilding things from scratch. Linked lists, web crawlers, you name it
